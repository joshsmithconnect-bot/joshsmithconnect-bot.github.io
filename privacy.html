PIP REBOOTED

Privacy policy

Last updated: November 17, 2026

Who this covers

"PIP Broadcast" is the software that runs the PIP Rebooted YouTube channel (youtube.com/@piprebooted). It is used only by the channel's owner, to manage that one channel. It is not offered to other people, and no one else can sign in to it.

What it accesses, and why

With the channel owner's permission, granted through Google's sign-in, the software uses the YouTube Data API and YouTube Analytics API to:

  • create, start and end the channel's own live broadcasts;
  • upload the channel's own Shorts;
  • read the channel's own video details and view statistics, to check that broadcasts were archived and to track the channel's progress.

It does not read, collect or store information about viewers, commenters or any other YouTube user.

Where data is kept

The sign-in token and the channel's own statistics are stored only on the channel owner's computer. Nothing is sent to any server other than Google's own APIs. Nothing is sold, shared, or used for advertising.

Google API Services

The software's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The channel owner can revoke the software's access at any time at myaccount.google.com/permissions. Revoking access stops all use; the locally stored token can then be deleted.

Contact

Questions about this policy: use the contact details on the PIP Rebooted channel's About page.
